# Instrucciones para agentes

Las reglas de este proyecto viven en [`AGENTS.md`](AGENTS.md), en un solo lugar.

Este archivo se mantiene como enlace porque algunas herramientas leen `CLAUDE.md` y otras
`AGENTS.md`, y dos copias de las mismas reglas terminan divergiendo. La fuente es `AGENTS.md`.

El instalador de Laravel deja aquí un marcador que pide instalar `laravel/boost`. **No se ha
instalado**: es una dependencia de desarrollo que no está en el plan aprobado. Si el titular
decide incorporarla, se regeneran ambos archivos con las guías que Boost produce.
