# Los secretos del despliegue, por su NOMBRE. Aquí no hay ni un valor.
#
# Por qué existe este archivo (ADR-0019). Los valores viven en UN solo sitio del
# mundo: `/etc/sede/<entorno>.secretos.env` en el servidor, de `root` y con
# permisos 600. No están en este repositorio —que es público—, no están en
# GitHub Actions y no viajan dentro de ninguna imagen. Lo que sí hace falta en
# el repositorio es la LISTA de nombres, por tres razones:
#
#   1. `deploy/droplet/despliegue-remoto.sh` la lleva escrita (es el ancla de
#      confianza del anfitrión y no puede leerla de una imagen, que es contenido
#      que podría manipular quien empuje al registro). Una guarda de la
#      canalización comprueba que las dos listas coinciden: si alguien añade un
#      secreto aquí y se olvida del guion, el despliegue lo diría en el servidor;
#      la guarda lo dice antes.
#   2. La canalización comprueba que cada marcador `${…}` de `deploy/plantilla.env`
#      está cubierto por esta lista o por `deploy/valores-<entorno>.env`. Añadir una
#      variable a la plantilla y que nadie la provea deja de ser un fallo de
#      despliegue y pasa a ser un fallo de integración.
#   3. Un nombre de esta lista NO puede declararse en los archivos de valores, que
#      sí viajan en la imagen. Así, quien empujara una imagen manipulada no puede
#      inyectar la clave de la base de datos ni la del super-admin: el guion
#      rechaza el archivo de valores que lo intente.
#
# Formato: `NOMBRE obligatorio` o `NOMBRE opcional`, una por línea.
#
#   obligatorio  tiene que estar en el archivo de secretos y NO puede estar vacío.
#                Vacío es peor que ausente: pasa una comprobación de presencia y
#                falla al usarse, a mitad del despliegue.
#   opcional     si no está, se renderiza vacío. Es la convención que ya usa la
#                plantilla para declarar una integración APAGADA: un botón que no
#                lleva a ninguna parte es peor que decir que no está.

# --- Sin estos cuatro, la pila no arranca o arranca insegura ------------------
